建立并初始化数据库
init_db():程序启动时，确保数据库和 students 表已经存在。
def init_db():
    conn = sqlite3.connect("students.db")   #如果 students.db 不存在，SQLite 会自动创建。 这里的connect相当于打开连接
    cursor = conn.cursor()
    cursor.execute("""              
    CREATE TABLE IF NOT EXISTS students(                      
    id INTEGER PRIMARY KEY,   
    name TEXT,
    age INTEGER,
    score REAL
 )
 """)   #执行 CREATE TABLE IF NOT EXISTS接着表结构
    conn.commit()
    conn.close()

def add_student(name, age, score):
    conn = sqlite3.connect("students.db")   #如果 students.db 不存在，SQLite 会自动创建。 这里的connect相当于打开连接
    cursor = conn.cursor()   #创建执行 SQL 的 cursor
    cursor.execute("INSERT INTO students(name,age,score) VALUES(?,?,?)",(name,age,score))
    conn.commit()
    conn.close()

def get_students():  #把数据库里的所有学生查出来并返回。
    conn = sqlite3.connect("students.db") 
    cursor = conn.cursor()
    cursor.execute("SELECT *FROM students")
    students = cursor.fetchall()  #取出全部结果
    conn.close()
    return students #这个函数的职责要求把查询结果交出去，所以这里需要 return students。

答：因为python不认识SQL语句

4.占位符和参数的对应情况

5.为什么get_students() 最后用return students

def delete_student(name):
    conn = sqlite3.connect("students.db") 
    cursor = conn.cursor()
    cursor.execute("DELETE FROM students WHERE name = ?",(name,))  #"SQL语句",(name,)别忘了逗号  不需要多扩一层括号
    conn.commit()
    conn.close()
    
def update_score(name, new_score):
    conn = sqlite3.connect("students.db") 
    cursor = conn.cursor()
    cursor.execute("UPDATE students set score = ? WHERE name = ?",(new_score,name,))    #不是form 而是直接update students  而且set后面要有列的值
    conn.commit()                                                   #只有单元素 tuple时，逗号才是必须的 么有逗号只能算字符串
    conn.close()

现在 SQLite V2 里，数据的长期存放位置是：students.db
当某个功能需要数据时，不是依赖 main() 里一直维护的 students 列表，而是由 database.py 临时去数据库里取

execute() 		告诉数据库“我要做这个修改”

commit()		正式确认并保存这次修改

如果不用close？

conn.close()	释放这次数据库连接占用的资源 
连接资源一直占着
→ 文件句柄 / 数据库资源越来越多
→ 某些情况下出现数据库锁定、资源耗尽
→ 程序长期运行时更容易出问题
可以记住：用完数据库连接就关闭，避免资源一直被占用

id INTEGER PRIMARY KEY 
在 SQLite 里，这种 INTEGER PRIMARY KEY 通常会让每条新记录自动得到一个唯一整数值，所以
唯一标识一条记录
→ 即使两个人同名，也能区分
→ 后续修改 / 删除时可以精确定位某一条数据
