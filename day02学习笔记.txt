变量可以理解成一个带名字的盒子。

例如：name = "张三"

print(name)Python 就知道：去名叫 name 的盒子里，把内容拿出来。

attention：左边永远是变量名    右边永远是值。

name = "小明"不是：name 等于小明

而是：把 "小明" 放进名字叫 name 的变量中。

数据类型
① 字符串（str）字符串就是：文字
所有文字都要加：" "或者：' '

② 整数（int）
整数不要加引号。
正确：age = 22
错误：age = "22"

③ 小数（float）
price = 19.9

④ 布尔值（bool）
只有两个值：
True
False
例如：is_student = True

print 输出
例如：
name = "小明"
age = 22

print(name, age)

input 输入
真正的程序：不是写死数据。
而是：让用户输入。
例如：
name = input("请输入姓名：")
print(name)

今日收获
input() 得到的数据永远都是字符串（str），不取决于用户输入的内容。
例如：
你输入：100 input 返回得到："100"
永远先思考：变量里面保存的到底是什么类型的数据？
